2.1 接口、安全与代码规范升级

旧规格保留默认行为；开启生产配置会改变协议、权限接口和数据库结构。

  1. 备份data和已有工程，替换同平台JAR。
  2. 检查生产配置，确认记录权限、更新／删除版本保护和审计白名单。
  3. AccessGuard接入可信身份和对象权限，分页必须保证整个SQL范围及总数均可读。
  4. 独立工程提供同事务JDBC审计；宿主须实现AuditWriter并共享业务事务，失败回滚。
  5. 更新两份ID必须一致；校验反馈使用业务字段，$表示请求整体。宿主映射RequestMismatchException为400。
  6. Java代码展开为四空格、控制块和中文说明；使用三方合并保留人工代码。
  7. 按生成的acceptance-checklist.md完成真实权限、并发、审计、MySQL迁移及恢复验收。

2.1.0 生产接入改进

从生成页检查生产配置，或载入权限与删除保护示例。生产检查的INCOMPLETE表示接入或实际验收未完成，不能把Mock PASS作为上线凭据。

已有能力

2.0.1支持字符串数值、码点长度、可信服务端字段、机构范围SQL、业务索引和Hooks。旧规格schemaVersion=1仍保留兼容数值协议，必须显式切换并回归。

本次改进

新增必需AccessGuard权限适配Bean、删除版本原子条件、生产缺口报告、字段级错误、完整业务字段请求样例及生产配置参考；修复字符串数据库默认值按UTF-16计长的遗漏。未提供权限Bean会启动失败；测试允许访问实现仅在测试目录。

接入流程

  1. 备份data和现有工程，替换同平台JAR。
  2. 载入当前规格，检查生产配置。应用基础配置会改变数值协议并要求实现Bean。
  3. 确认SERVER scopeField，配置业务唯一索引；实现真实权限、业务状态与同事务审计。
  4. 用三方合并保留现有人工实现，下载后在真实宿主编译。
  5. 验证越权、并发、幂等、MySQL迁移、性能、备份恢复后发布。

代码生成不包含完整IAM、审批系统、幂等结果存储、消息投递和自动存量迁移；报告逐项显示这些缺口。
